aster 0.1.1 发布包含 macOS Apple Silicon 安装包、Windows x64 安装包，以及银河麒麟 V10 x86_64 离线安装包。

相对 0.1.0：

- 修复首次创建知识笔记或文件夹失败。
- 修复模型设置重启后丢失，以及删除模型后重新出现。正在作为默认值的模型需要先切换默认值，再删除。
- 历史版本保存的 `enabled:false` 模型会继续以禁用状态显示。若不再需要，请再次删除；本版不会自动清除这些历史记录。
- 桌面会话使用文件内容摘要进行自动完成校验，保留原有完成门禁和工作区路径边界。
- 移除独立证据份数上限。终端未配置档位时默认 medium，即 48 个工具轮次；命令行和已配置的档位仍可覆盖。
- 预算停止原因写入会话记录；桌面保留已有回复，并按结构化原因区分检索收尾和真正未完成。
- 非法表单立即返回错误并恢复输入；已正确显示的表单允许持续等待填写。
- 修复打包版 JSON 编辑器的行重叠和滚动时固定标题区域透明叠字。

- 已验证安装包和包内应用均通过 Gatekeeper。

## 银河麒麟 V10

下载 `aster_0.1.1_kylin-v10_x86_64.run`。在麒麟电脑上用桌面登录用户执行：

```bash
bash aster_0.1.1_kylin-v10_x86_64.run
```

不要加 sudo。这是一个离线安装包，内含 GNOME Platform 50、图形运行时和应用。重复安装保留用户数据。

SHA-256：

```text
e4add14e1136b1fa5dd0c5a0dd5054abc7b453d72175f105219d15b821f580eb  aster_0.1.1_kylin-v10_x86_64.run
```

同时提供 `aster_0.1.1_kylin-v10_x86_64.run.sha256`。

麒麟包装载 fcitx5 的 GTK3 输入法模块。会话拥有 Fcitx5 时由该模块提交文字。尚未在银河麒麟实机上验证首页中文输入。只有 fcitx4 或搜狗时，中文提交仍然不可用。应用内检查更新不能替换这个已安装的 Flatpak，下一版仍用新的 `.run` 覆盖安装。

麒麟包的构建来源是本地工作区，宿主提交 `18144aab129d`，并包含当时尚未提交的输入法模块变更。此发布没有把这些源码变更提交或推送到 `main`，也没有移动标签 `v0.1.1`。
