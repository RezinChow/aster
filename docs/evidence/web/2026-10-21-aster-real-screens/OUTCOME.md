# Aster 真实界面与设计规范对齐

按用户反馈，替换上一版手工重绘的应用演示。官网保留 `/aster/` 地址，不创建组织根站仓库。

## 结果

- 工作区、Office、自动审查及产物追溯四张图片，均由实际生产界面组件运行后采集。首页主图是真实的对话与 DOCX 分屏，Office 图是真实电子表格编辑器。网页仅提供图片展示、放大和原图链接。
- 四张 PNG 与采集原图逐字节一致，未裁剪、拼接、修图或改写产品 CSS。图片使用隔离的合成项目、文档及记录，不包含个人会话或凭据。来源和哈希见 `capture.json`。
- 网站组件按根 `DESIGN.md` 对齐：中性色导航与选中态、13px 控件、8px 按钮、白色分段选项、12px 弹窗、黑色 20% 遮罩、160/200ms 原位动效及低动态效果退化。字体随站点发布 Ubuntu 与完整许可。
- Canvas 轨道与星点保留为装饰层；后台或离屏停止动画。右下角回顶按钮保留。禁用 JavaScript 后，下载和原图链接仍可使用，四个功能区仍可阅读。
- 发布目录只有 15 个公开文件，包含页面、截图、字体、许可、logo 和根入口；不包含私有界面源码、构建 bundle、其他租户、依赖或用户状态。

## 验证

- Python 静态合同：17 项通过。
- DOM 交互与 Canvas 调度：18 + 7 项通过。
- 实际浏览器 ACL：桌面 25 步、移动端 17 步全部通过，两个场景页面错误均为空，清理成功。
- 本地 `/aster/` 发布目录：22 项 HTTP 检查通过，15 个文件与源字节一致，私有及额外路径被拒绝。
- 对真实截图与网站浏览器截图进行了视觉检查；设计角色对照、资源闭包、JS 语法及限定差异检查通过。

## Explicitly not claimed

真实界面截图使用合成的服务响应与演示数据；这证明实际组件的显示，不代表原生窗口、真实模型、文件生成或自动审查的功能验收。采集时发现启用审查的浮层可能覆盖最大化 Office；Office 和分屏截图使用审查关闭的另一个正常任务策略，没有通过图像处理掩盖问题。该产品问题保留在采集记录中，本次不修改产品逻辑。

没有重新构建或发布桌面安装包；公开旧包可能早于这些界面。桌面 CI 仍因缺少私有依赖读取凭据而在检出前停止，官网 CI 独立运行；本次不复制凭据或放宽权限。历史第一版证据保持原样。
