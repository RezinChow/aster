# Aster 下载站与品牌统一

下载站采用参考下载页的 64px 顶栏、1100×700 桌面预览、居中首屏和分段展示结构，改用 Aster 蓝色与现有星轨 logo。内容围绕当前产品的工作区、Office、按需自动审查和产物追溯；交互示意使用合成数据，不运行真实任务。

## 已完成

- 四个功能标签各有对应说明与界面。工作区示例保留对话、文件标签、Office 编辑视图及产物来源；审查与追溯开关对应真实输入框选项，默认关闭。
- Canvas 细轨与星点支持低动态效果设置；离屏、后台停止绘制。移动端将缩略图设为不可交互，展开后使用同一份可操作界面。
- 滚动 600px 后显示右下角回顶按钮；返回首屏后隐藏。下载控件在无 JavaScript 时仍能前往发行页。
- 默认桌面产品源码统一命名为 Aster。应用标识、用户数据目录和另一租户行为保持兼容；私有宿主只以 gitlink 记录。
- Pages 流程不检出子仓库，只上传四个官网文件、两个 logo 及一个根入口，共七个文件。

## 验证

- `python3 -m unittest discover -s apps/web/tests -p 'test_*.py' -v`：13 项通过。
- 公开、隔离的 `jsdom@26.1.0` 运行 DOM 与 Canvas 测试：19 项通过。
- `a3s-test run apps/web/tests/download.acl --browser-driver standalone --json`：桌面 1440×900 的 26 步、移动端 390×844 的 34 步全部通过。两场景收集的页面错误均为空。
- 首轮真实浏览器测试发现全局平滑滚动使远处控件首次点击未生效；去掉全局滚动动画后原断言全部通过。回顶按钮保留显式平滑滚动并遵循低动态效果设置。
- 静态合同验证六个确实存在的发行链接、本地资源、锚点、控件名称与隔离部署目录。源码与部署文件摘要见 `validation.json`。
- `tests/just_work.py`：9 项通过。桌面品牌对应的原生、发行脚本、前端检查保存在私有宿主的本次更名证据目录中。
