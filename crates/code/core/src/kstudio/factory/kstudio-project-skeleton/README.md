# 项目 AI 工程

.aster 记录本项目的目标、编排与验证证据。初始化仅建立结构，不代表产品验收。

从 `/goal` 澄清总体目标，以 `/task` 处理当前任务，以 `/plan` 规划全项目。
`/review` 检查改动与证据；`/clean` 先出清单。角色与资源须显式晚绑定。

```bash
python3 .aster/workflow/sync-k-skills.py --check
python3 .aster/workflow/verify-ai-eng.py --level L3
```
